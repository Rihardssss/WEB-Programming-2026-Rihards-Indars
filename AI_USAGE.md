# Mākslīgā intelekta izmantošana

**Vārds, uzvārds:** Rihards Indārs  
**Izmantotais(-ie) MI rīks(-i):** Claude

## Kam es izmantoju mākslīgo intelektu?

- Lai izskaidrotu, kas ir Tailwind CSS un kā strādā utility-first pieeja, jo pirms tam par to neko nezināju
- Lai palīdzētu uzstādīt Vite + Tailwind projektu
- Lai palīdzētu pārrakstīt HTML un JS kodu no parastā CSS uz Tailwind klasēm

## Kuru kodu vai konfigurāciju būtiskā apjomā ģenerēja mākslīgais intelekts?

- Tailwind klases index.html failā
- app.js kods
- vite.config.js un style.css theme daļa

## Kuru kodu vai konfigurāciju es uzrakstīju pats/pati vai būtiski pārveidoju?

- Liku izņemt komentārus no koda
- Pats izlēmu commit sadalījumu un ziņojumus
- Katru soli pats pārbaudīju pārlūkā pirms gāju tālāk

## Viens MI ieteikums, kuru es noraidīju vai izmainīju

Īsi paskaidrojiet savu izvēli: app.js sākumā bija ar garākiem komentāriem, es lūdzu tos izņemt, jo negribēju, lai izskatās pēc AI koda.

## Viena lieta, kuru es pārbaudīju pats/pati, nevis vienkārši uzticējos MI atbildei

Īsi paskaidrojiet, ko un kā jūs pārbaudījāt: Pēc katra soļa palaidu npm run dev un paskatījos pārlūkā, vai viss izskatās pareizi - mobilo izvēlni, filtrus, izkārtojumu dažādos ekrāna izmēros.
