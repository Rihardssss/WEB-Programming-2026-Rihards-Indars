# Individuālā refleksija

Aizpildiet šo daļu individuāli nodarbības beigās, **neizmantojot mākslīgā intelekta rīkus**.

Ieteicamais kopējais apjoms: **aptuveni 200–300 vārdi**.

---

## 1. Utility-first CSS pieeja

Tailwind izmanto mazas gatavas klases, piemēram, p-4, text-center, flex.
Tās var salikt uzreiz HTML elementam.
Iepriekš lielākā daļa noformējuma bija styles.css, bet ar Tailwind daudzi stili atrodas pašā HTML.
---

## 2. Divi migrācijas piemēri

Sākumā CSS noteica izvēlnes izkārtojumu, atstarpes un krāsas. Tailwind izmantoju flex, items-center, justify-between, p-4 un citas klases, lai iegūtu līdzīgu izskatu.

Projektu filtrs:
Sākotnējais CSS noteica pogu izmēru, atstarpes un izskatu. Tailwind izmantoju px-4, py-2, rounded, border un hover: klases.
---

## 3. Jūsu vērtējums

Tailwind man šķiet ērtāks, kad vajag ātri izveidot izkārtojumu un nav visu laiku jāmeklē vajadzīgais CSS fails.

Parasto CSS es izvēlētos situācijās, kad vajag sarežģītākus vai ļoti specifiskus stilus, kur daudz tailwind kļūst neērti rakstīt.
