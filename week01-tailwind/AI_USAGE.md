# Mākslīgā intelekta izmantošana

**Vārds, uzvārds:** Rihards Indārs
**Izmantotais(-ie) MI rīks(-i):** Claude

## Kam es izmantoju mākslīgo intelektu?

- Lai saprastu, kas ir Tailwind CSS un kā tas strādā
- Lai palīdzētu uzstādīt Vite un Tailwind projektu
- Lai pārveidotu HTML un JS kodu uz Tailwind klasēm

## Kuru kodu vai konfigurāciju būtiskā apjomā ģenerēja mākslīgais intelekts?

- Tailwind klases failā `index.html`
- `app.js` kodu
- `vite.config.js` un `style.css` izmaiņas

## Kuru kodu vai konfigurāciju es uzrakstīju pats/pati vai būtiski pārveidoju?

- Palūdzu izņemt liekos komentārus no koda
- Pats sadalīju darbu commitos un izdomāju to nosaukumus
- Pēc katra soļa pārbaudīju rezultātu pārlūkā

## Viens MI ieteikums, kuru es noraidīju vai izmainīju

Īsi paskaidrojiet savu izvēli: palūdzu izņemt garos komentārus no `app.js`, jo tie nebija vajadzīgi un padarīja kodu sarežģītāku.

## Viena lieta, kuru es pārbaudīju pats/pati, nevis vienkārši uzticējos MI atbildei

Īsi paskaidrojiet, ko un kā jūs pārbaudījāt: pēc katra soļa palaidu `npm run dev` un pārbaudīju pārlūkā, vai viss strādā pareizi, ieskaitot mobilo izvēlni, filtrus un izkārtojumu dažādos ekrānos.
