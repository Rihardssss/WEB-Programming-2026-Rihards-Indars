# Mākslīgā intelekta izmantošana

**Vārds, uzvārds:** Rihards Indārs
**Izmantotais(-ie) MI rīks(-i):** Claude

## Kam es izmantoju mākslīgo intelektu?

- Lai palīdzētu ar `fetch` un TypeScript tipiem
- Lai saprastu loading un error stāvokļus
- Lai palīdzētu ar Open-Meteo API

## Kuru kodu vai konfigurāciju būtiskā apjomā ģenerēja mākslīgais intelekts?

- `api.ts` un `guards.ts` kodu
- API pieprasījumu un datu pārbaudes piemērus
- Ielādes un kļūdu stāvokļu piemērus

## Kuru kodu vai konfigurāciju es uzrakstīju pats/pati vai būtiski pārveidoju?

- Pielāgoju JSON failus
- Sadalīju darbu commitos
- Pārbaudīju lapu ar DevTools
- Pievienoju atsevišķu `localStorage` atslēgu un laika apstākļu karti

## Viens MI ieteikums, kuru es noraidīju vai izmainīju

Īsi paskaidrojiet savu izvēli: neizmantoju `as` API datiem, bet gan type guard funkcijas, lai pārbaudītu, vai dati ir pareizi.

## Viena lieta, kuru es pārbaudīju pats/pati, nevis vienkārši uzticējos MI atbildei

Īsi paskaidrojiet, ko un kā jūs pārbaudījāt: ar DevTools pārbaudīju lēnu internetu un offline režīmu, lai redzētu, vai loading un error stāvokļi strādā pareizi.
