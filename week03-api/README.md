# CampusFlow — 3. nedēļa: dati no API

Šis ir **CampusFlow** projekta turpinājums. Sākuma punkts ir **jūsu pašu** 2. nedēļas rezultāts (`week02-typescript`) — atsevišķu sākuma failu šoreiz nav.

Līdz šim projekti un termiņi bija ierakstīti kodā (`data.ts`). Šajā nedēļā lapa tos **ielādē no API** ar `fetch`, pārbauda, vai atnākušie dati tiešām ir tādi, kā gaidīts, un parāda lietotājam, kas notiek: dati **ielādējas**, ielāde **neizdevās** vai datu **nav**. Lapa saņem arī īstus datus no ārēja API — pašreizējos laikapstākļus Rīgā.

## Faili

- `TASK.md` — praktiskā uzdevuma instrukcija;
- `AI_USAGE.md` — MI izmantošanas apraksta veidne;
- `REFLECTION.md` — individuālās refleksijas jautājumi.

Darbs turpinās tajā pašā GitHub repozitorijā (`web-programming-2026-vards-uzvards`), jaunā mapē `week03-api`.
