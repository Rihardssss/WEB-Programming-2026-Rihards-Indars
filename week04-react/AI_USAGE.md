# Mākslīgā intelekta izmantošana

**Vārds, uzvārds:** Rihards Indārs
**Izmantotais MI rīks:** Claude

## Kam es izmantoju mākslīgo intelektu?
- Lai palīdzētu ar HTML pārveidošanu uz React.
- Lai paskaidrotu dažas React funkcijas un props lietošanu.

## Kuru kodu būtiski ģenerēja MI?
- Dažas komponenšu sākotnējās versijas.
- Atsevišķus koda piemērus, kurus vēlāk pielāgoju.

## Ko es uzrakstīju vai pielāgoju pats?
- Pats veidoju un pielaboju komponenšu izkārtojumu.
- Pielāgoju filtrus un mobilās izvēlnes darbību.
- Mainīju JSON datus un pārbaudīju, vai viss pareizi attēlojas.
- Sadalīju darbu commitos un sakārtoju kodu.

## Viens MI ieteikums, kuru es izmainīju
MI ieteica izmantot useEffect datu ielādei, bet to šonedēļ nedrīkstēja izmantot, tāpēc izmantoju props no main.tsx.

## Ko es pārbaudīju pats?
Pārbaudīju filtra darbību pēc Try again klikšķa, kā arī palaidu build un lint, lai pārliecinātos, ka nav kļūdu.
